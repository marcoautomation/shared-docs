FEARLESS MANAGER - GUI TEST PLAN (draft v2)

Use fearlessManaged0_001w.exe (windowed launcher, no console window).

PRECONDITIONS (apply before Test 1, and before any test that is not
listed as continuing from the one before it):
- fearlessManaged0_001w.exe is not running.
- The manager data folder (fearless0_001, next to the app folder) is
  deleted.
- 01_hello_world/.fearless_out is deleted.
- Nothing owns the .fearless extension yet.

Projects used below:
- 01_hello_world, marker hello_world.fearless, registers as hello_world.
  Mains: Hello1, Hello3, Hello4, Hello5, Hello6. Hello6 errors on
  purpose (its output contains AAAAh) and exits non-zero; the rest
  exit 0.
- 02_mains_in_methods, registers as mains_in_methods.
- 09_gui_basics, registers as gui_basics. Its main never exits on its
  own.

TEST 1 - File association
1. Open Explorer on 01_hello_world.
   hello_world.fearless shows a generic icon.
2. Run fearlessManaged0_001w.exe.
   Manager window opens.
3. Refresh Explorer (F5).
   hello_world.fearless now shows the Fearless icon.
4. Manager menu -> Forget association -> Yes.
   Manager window closes.
5. Refresh Explorer.
   hello_world.fearless shows a generic icon again.
6. Run fearlessManaged0_001w.exe.
   Manager window opens.
7. Refresh Explorer.
   hello_world.fearless shows the Fearless icon again.

TEST 2 - Split view and divider
(continues from Test 1)
1. Project menu -> Add folder... -> select 01_hello_world.
   A hello_world tile appears, badged "needs compiling".
2. Click the hello_world tile.
   Window splits: icon grid on the left, project panel on the right,
   divider between them.
3. Drag the divider left, then right.
   Both panes resize live with the mouse.
4. Drag the divider to the right edge of the window.
   Only the icon grid is visible; it is still clickable.

TEST 3 - Compile and run
(continues from Test 2)
1. Click Compile.
   Output shows "--- compiling hello_world ---", then
   "--- compile done ---". Mains list shows Hello1, Hello3, Hello4,
   Hello5, Hello6.
2. Click the All button.
   All 5 checkboxes are checked.
3. Click Run selected.
   For each main, in order: "--- running <name> ---", its own output,
   "--- <name> exited with <code> after <N>s ---". Hello1/3/4/5 exit 0.
   Hello6's output contains AAAAh and it exits non-zero.
4. Scroll the output area from top to bottom.
   All 5 run blocks are present, none cut off.
5. Judge whether the default window and output size showed all of the
   above without manual resizing.
   If not, note it as a defect to fix.

TEST 4 - Second project
(continues from Test 3)
1. Project menu -> Add folder... -> select 02_mains_in_methods.
   A mains_in_methods tile appears.
2. Click the mains_in_methods tile.
   Panel switches to mains_in_methods.
3. Click the hello_world tile.
   Panel switches back; hello_world's output log is unchanged.
4. Open the Running menu.
   Shows "<nothing running>".

TEST 5 - Running program and Terminate
(continues from Test 4)
1. Project menu -> Add folder... -> select 09_gui_basics. Select it,
   Compile, check its main, click Run selected.
   A separate window opens; Terminate becomes enabled.
2. Open the Running menu.
   Shows "gui_basics - <main name>".
3. Click that entry.
   gui_basics panel opens.
4. Click Terminate.
   Output shows "--- terminating <main> ---" then an exited line.
   Running menu returns to "<nothing running>".

TEST 6 - Window close vs Quit
(continues from Test 5)
1. Click the window's X (title bar close button).
   Window disappears; a tray icon remains.
2. Double-click the tray icon.
   Window reappears, state intact.
3. Manager menu -> Quit manager.
   Window closes and the process exits; tray icon disappears.

TEST 7 - Nested folder rejected
(fresh precondition state, then register hello_world same as Test 2
step 1)
1. Project menu -> Add folder... -> select a subfolder inside the
   already-registered 01_hello_world (e.g. _hello).
   No tile is added; a warning dialog names both folders.
2. Dismiss the dialog.
   Icon grid is unchanged.

TEST 8 - Clear cache and Forget project
(fresh precondition state, then register and compile
02_mains_in_methods)
1. Select mains_in_methods. Project menu -> Clear cache.
   "Compiled cache" becomes "needs compiling"; mains list becomes
   "<needs compiling>".
2. Project menu -> Forget project.
   Tile disappears; panel closes.
3. Check 02_mains_in_methods on disk.
   Nothing was deleted.
