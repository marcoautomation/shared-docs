ECLIPSE: IMPORT FEARLESS TEST RESULTS INTO THE JUNIT VIEW
Running the Coordinator test suite (the console-launcher script, or
Eclipse's own JUnit runner) writes every individual Fearless-level check
to Coordinator/.out/junit_xml/all_auto_tests.xml, already shaped as real
JUnit XML.
1. Window > Show View > Other... > Java > JUnit, if the view isn't open.
2. In the JUnit view's toolbar, click the small dropdown next to the
   clock-with-arrow ("Test Run History") icon, choose Import..., and pick
   all_auto_tests.xml.
Eclipse rebuilds the whole run as a real tree, one node per project and
one leaf per Fearless-level check, individually pass/fail/skip. Add a
project with Fearless-level tests later and it just shows up in the same
file next time you import it - nothing new to pick.
Full write-up (how this was wired up, screenshots, a standalone converter
for projects outside Coordinator):
https://marcoautomation.github.io/shared-docs/fearless/eclipse-tests/
